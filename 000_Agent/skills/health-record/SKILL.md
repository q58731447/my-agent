# 每日健康紀錄存入 Heptabase

---

## 步驟零：判斷來源

### 情況 A：使用者沒有貼入任何內容（只說「體重紀錄」「健康紀錄」等）

1. 詢問：
   ```
   要讀取哪一天的 Journal？（直接回覆日期，例如 2026-06-15，或說「今天」）
   ```

2. 收到日期後，呼叫 `get_journal_range`，startDate 與 endDate 皆設為該日期（格式 YYYY-MM-DD）。

3. 從回傳內容中，找出所有符合以下結構的區塊（可能有多筆）：
   - **開始標記**：`請生成今天的《輕身江湖錄》。`
   - **結束標記**：`體重紀錄結束`

4. 若找不到任何區塊，告知使用者：
   ```
   ⚠️ 該日 Journal 中找不到健康紀錄區塊（需包含「請生成今天的《輕身江湖錄》。」與「體重紀錄結束」標記）。
   ```
   然後停止流程。

5. 找到幾筆，就依序對每一筆執行步驟一～五。

---

### 情況 B：使用者說「更新YYYYMMDD週資料」

→ 進入文末的「**週紀錄上傳流程**」，不走步驟一～五。

---

### 情況 C：使用者直接貼入紀錄內容

直接進入步驟一，不詢問、不確認。

---

## 步驟一：解析欄位

從紀錄中擷取以下欄位（若欄位空白或未提供，標記為「未填寫」）：

- **日期**：格式 YYYYMMDD（取 `日期：` 欄位）
- **今日體重**（kg）
- **昨日體重**（kg）
- **入睡時間**（HH:MM，24 小時制）
- **超慢跑時間**（分鐘，無紀錄則為 0）
- **早餐**：內容、結果、評語
- **午餐**：內容、結果、評語
- **晚餐**：內容、結果、評語
- **點心**：`是否有含糖或油炸點心`（是/否）、點心內容、點心結果
- **心得**（選填，取「心得」段落至 `體重紀錄結束` 之間的文字）

**結果欄位對應規則：**

| Journal 原文 | 判斷 |
|-------------|------|
| 未超標 | 未超標 |
| 已超標、超標、微超標、稍微超標、明顯超標 | 超標（視為未達成） |

---

## 步驟二：計算達成率

共 **9 個目標**，逐一判斷：

| # | 名稱 | 目標 | 達成條件 |
|---|------|------|---------|
| 1 | 子時歸息 | 於 24:00（子時）前入睡 | 入睡時間 ≤ 23:59 |
| 2 | 亥末調息 | 於 23:50 前入睡 | 入睡時間 ≤ 23:50 |
| 3 | 月落養神 | 於 23:30 前入睡 | 入睡時間 ≤ 23:30 |
| 4 | 輕功步訣 | 完成超慢跑（有開始即達成） | 超慢跑時間 > 0 分鐘 |
| 5 | 晨膳守量 | 早餐份量未超標 | 早餐結果 = 未超標 |
| 6 | 午膳守量 | 午餐份量未超標 | 午餐結果 = 未超標 |
| 7 | 暮膳守量 | 晚餐份量未超標 | 晚餐結果 = 未超標 |
| 8 | 戒口清心 | 未食含糖油炸點心或份量未超標 | 點心結果 = 未超標，**或**當天無點心 |
| 9 | 收功存錄 | 完成今日體重、睡眠、運動、飲食全紀錄 | 使用者提交當日完整紀錄（預設達成） |

**達成率 = 達成數 ÷ 9 × 100%**（四捨五入，取整數）

---

## 步驟三：組合卡片內容

### 卡片標題格式

```
[YYYYMMDD][健康紀錄][達成率%]
```

### 卡片內容格式（純文字）

```
日期：YYYYMMDD
今日體重：XX.X kg　昨日體重：XX.X kg　體重變化：±X.X kg

入睡時間：HH:MM
超慢跑：XX 分鐘

---
【早餐】
內容：...
結果：...
評語：...

【午餐】
內容：...
結果：...
評語：...

【晚餐】
內容：...
結果：...
評語：...

【點心】
有無：有 / 無
內容：...
結果：...

---
【心得】
...（若無心得則省略此區塊）

---
【今日達成率】
① 子時歸息（24:00前入睡）：✅ 達成 / ❌ 未達成
② 亥末調息（23:50前入睡）：✅ 達成 / ❌ 未達成
③ 月落養神（23:30前入睡）：✅ 達成 / ❌ 未達成
④ 輕功步訣（超慢跑有開始即達成）：✅ 達成 / ❌ 未達成
⑤ 晨膳守量（早餐未超標）：✅ 達成 / ❌ 未達成
⑥ 午膳守量（午餐未超標）：✅ 達成 / ❌ 未達成
⑦ 暮膳守量（晚餐未超標）：✅ 達成 / ❌ 未達成
⑧ 戒口清心（點心未超標）：✅ 達成 / ❌ 未達成
⑨ 收功存錄（完成全紀錄）：✅ 達成 / ❌ 未達成

達成：X / 9　達成率：XX%
```

**格式補充說明：**
- 體重變化 = 今日體重 − 昨日體重，負數顯示為「−X.X kg（減輕）」，正數顯示為「+X.X kg（增加）」，0 顯示為「0 kg（維持）」
- 評語若空白，省略評語那行
- 當天無點心，【點心】區塊寫「無（視為達成）」
- 未填寫的欄位填入「未填寫」，對應目標判定為未達成

## 步驟四A：存入本機（先備份，再上傳）

> ⚠️ **先執行此步驟，再執行步驟四B。**

使用 Write 工具，將步驟三的卡片內容存入本機：

- **路徑**：`C:\Users\Jeff Chen\iCloudDrive\Claude\my-agent\health-records\YYYYMMDD.md`
- **內容**：步驟三的純文字卡片內容（第一行為 `# [YYYYMMDD][健康紀錄][XX%]`）
- 若檔案已存在，直接覆蓋

---

## 步驟四B：存入 Heptabase

> ⚠️ **必須使用 `save_to_note_card`，絕對不可使用 `append_to_journal`。**

呼叫 `save_to_note_card`：
- **content**：第一行為 `# [YYYYMMDD][健康紀錄][XX%]`，後續為步驟三的卡片內容

存入完成後，告知使用者：

```
✅ 健康紀錄已存入！
卡片標題：[YYYYMMDD][健康紀錄][XX%]
本機備份：health-records/YYYYMMDD.md
今日達成：X / 9 項目標

⚠️ 提醒：請到 Heptabase 主空間，將此卡片手動移入「我的健康人生」白板。
```

若同一次有多筆紀錄，每筆完成後都輸出一次確認，全部完成後輸出總結。

---

## 步驟五：草擬 Threads 貼文並詢問是否發佈

> ⚠️ **不需詢問帳號，直接草擬貼文。** 確認發佈時才詢問帳號。
> 若同一次有多筆紀錄，詢問使用者要草擬哪一天的貼文（或全部）。

### Threads 貼文格式

```
【瘦身日誌 YYYY.MM.DD】

⚖️ 體重：XX.X kg（↓/↑/維持）
😴 入睡：HH:MM
🏃 超慢跑：XX 分鐘
🎯 達成：X / 9（XX%）

子時歸息：於 24:00 前入睡（✅/❌）
亥末調息：於 23:50 前入睡（✅/❌）
月落養神：於 23:30 前入睡（✅/❌）
輕功步訣：完成超慢跑（✅/❌）
晨膳守量：早餐份量未超標（✅/❌）
午膳守量：午餐份量未超標（✅/❌）
暮膳守量：晚餐未超標（✅/❌）
戒口清心：未食含糖油炸點心（✅） / 因為有吃 XX 所以（❌）
收功存錄：完成今日全紀錄（✅/❌）

---

（若使用者有心得文字，整理為自然段落插入此處；無心得則省略此區塊與分隔線）

#健康管理 #超慢跑 #每日紀錄 #瘦身日誌
```

**撰寫規則：**
- 體重變化為 0 寫「維持」；負數寫「↓X.X kg」；正數寫「↑X.X kg」
- 達成率 ≥ 78%（7/9 以上）可加一句正向收尾，< 45%（4/9 以下）則寫一句輕描淡寫的反思（不批評）
- 超慢跑為 0 分鐘，輕功步訣標記 ❌；有開始（>0 分鐘）即算 ✅
- 無點心當天，戒口清心標記 ✅，欄位仍保留
- 戒口清心標記 ❌ 時，需帶入具體點心名稱（格式：「因為有吃 XX 所以（❌）」）
- 語氣需像真人在寫日記，避免「今天表現很好」「持續努力」等制式用語
- 全文（含心得）不超過 500 字

### 詢問確認

草擬完成後，詢問：


## 週紀錄上傳流程（獨立指令）

**觸發條件**：使用者說「更新YYYYMMDD週資料」

### 1. 計算週區間

給定日期 D：

- 若 D 是**週一**：週區間 = (D − 7 天) 至 (D − 1 天)，即前一週的週一到週日
- 若 D **不是週一**：週區間 = D 所在週的週一 至 D 所在週的週日

範例：「更新20260615週資料」→ 20260615 是週一 → 週區間 = 20260608（週一）～ 20260614（週日）

### 2. 讀取本機日檔

依序讀取以下 7 個檔案：
```
C:\Users\Jeff Chen\iCloudDrive\Claude\my-agent\health-records\YYYYMMDD.md
```
（YYYYMMDD 依序為週一到週日）

- 有檔案：讀取完整內容
- 無檔案：標記為「未填寫」

### 3. 組合週卡內容

```
# [YYYYMMDD-YYYYMMDD][體重週紀錄]

## YYYYMMDD（週一）
（日卡完整內容，去掉第一行的 # 標題）

---

## YYYYMMDD（週二）
（日卡完整內容）

---

## YYYYMMDD（週三）
未填寫

---

...（依序至週日）
```

**中文星期對應：**
週一、週二、週三、週四、週五、週六、週日

### 4. 存入本機週檔

路徑：`C:\Users\Jeff Chen\iCloudDrive\Claude\my-agent\health-records\week-YYYYMMDD-YYYYMMDD.md`

內容 = 步驟 3 的週卡完整內容

### 5. 上傳至 Heptabase

呼叫 `save_to_note_card`：
- **content**：步驟 3 的週卡完整內容（第一行已含 `# [YYYYMMDD-YYYYMMDD][體重週紀錄]`）

完成後告知：

```
✅ 週紀錄已上傳！
卡片標題：[YYYYMMDD-YYYYMMDD][體重週紀錄]
本機備份：health-records/week-YYYYMMDD-YYYYMMDD.md
本週已填寫：X / 7 天

⚠️ 提醒：請到 Heptabase 主空間，將此卡片手動移入「我的健康人生」白板。若已有舊版週卡，請手動刪除。
```
