# 語法卡片建立 SOP

## 步驟零：判斷觸發類型

### 情況 A：使用者說「上傳YYYYMMDD週資料」

→ 進入文末的「**週索引上傳流程**」，不走步驟一～二。

### 情況 B：使用者提供語法內容

直接進入步驟一。

---

## 分類系統

根據內容自動判斷，無需使用者選擇：

| 分類碼 | 適用內容 | 子分類選項 |
|--------|----------|-----------|
| `[AI]` | 給 AI 模型的提示詞語法 | 角色設定 / 輸出格式 / 思維框架 / 限制條件 / 情境注入 |
| `[IMG]` | 圖片生成提示詞 | 人像 / 場景 / 文字排版 / 圖表資訊圖 / 風格指定 |
| `[DB]` | AI 工具語法與指令 | Claude / Gemini / ChatGPT |
| `[LEARN]` | AI 學習筆記與創作方法 | 創作流程 / 工具技巧 / 提示詞策略 / 工作流整合 / 案例拆解（可複合）|

---

## 步驟一：自動產生標題並確認

收到語法內容後，根據內容：
1. 判斷分類碼（[AI] / [IMG] / [DB] / [LEARN]）
2. 判斷子分類（[LEARN] 可填複合型，例如：創作流程 + 工具技巧）
3. 產生簡潔的繁體中文標題

**標題格式**：`[P][分類碼][標題]`

**範例**：
- `[P][AI][鏈式思考提示框架]`
- `[P][IMG][夢幻向日葵田場景]`
- `[P][DB][Claude 系統提示角色設定語法]`
- `[P][LEARN][用 Midjourney 完成品牌視覺的完整流程]`

詢問使用者：
> 「建議標題：**[P][AI][XXXX]**，這個標題可以嗎？」

---

## 語言處理規則

存入前先判斷輸入語言：

| 輸入語言 | 處理方式 |
|----------|----------|
| **繁體中文** | 直接存入，不做轉換 |
| **簡體中文** | 無條件全文轉換為繁體中文後存入 |
| **英文** | 原文保留英文，額外新增【原文翻譯】欄位，填入繁體中文翻譯 |

## [LEARN] 分類專屬流程

當判斷為 `[LEARN]` 分類時，標題確認後，**不直接存入**，改為先詢問三個欄位：

**詢問順序**（逐一詢問，等待回答）：

1. > 「你使用的 AI 工具是什麼？（【應用工具】欄位，可跳過）」
2. > 「有沒有你自己的心得或備註要加入？（【我的心得 / 備註】欄位，可跳過）」
3. > 「有參考來源要附上嗎？（【參考來源】欄位，例如文章連結、書名，可跳過）」

收集完畢後，存入以下格式的卡片：

```
【子分類】
（AI 自動判斷，複合型用「+」連接，例如：創作流程 + 工具技巧）

【核心概念】
（AI 根據輸入內容自動提煉 2-3 句核心觀念）

【應用工具】
（使用者提供；若跳過則填「未指定」）

【執行步驟 / 流程】
（AI 根據內容自動整理為可執行的步驟或流程）

【我的心得 / 備註】
（使用者提供；若跳過則留空）

【參考來源】
（使用者提供；若跳過則留空）

【參考圖片】
（留空，使用者手動上傳）
```

存入完成後，立即執行**步驟三：更新本機週索引**。

## 步驟三：更新本機週索引

> ⚠️ **每張卡存入 Heptabase 後（含 [LEARN] 流程），立即執行此步驟。**

### 計算本週區間

給定今日日期，計算本週週一到週日（ISO 週，週一為起點）。

### 讀取或建立週索引檔

路徑：`C:\Users\Jeff Chen\iCloudDrive\Claude\my-agent\syntax-cards\week-YYYYMMDD-YYYYMMDD.md`

- 若檔案已存在：讀取現有內容，在表格末尾 append 新的一筆
- 若檔案不存在：建立新檔，寫入標題與表格標題列

### 週索引檔格式

```markdown
# 語法卡片週索引 YYYY.MM.DD～YYYY.MM.DD

| 日期 | 分類碼 | 標題 |
|------|--------|------|
| YYYY-MM-DD | [AI] | 鏈式思考提示框架 |
| YYYY-MM-DD | [LEARN] | 用 Midjourney 完成品牌視覺的完整流程 |
```

- **日期**：今日日期（YYYY-MM-DD）
- **分類碼**：`[AI]` / `[IMG]` / `[DB]` / `[LEARN]`
- **標題**：卡片標題中的最後一段（去掉 `[P][分類碼]` 前綴）

## 週索引上傳流程（獨立指令）

**觸發條件**：使用者在 syntax-card skill 內說「上傳YYYYMMDD週資料」

### 1. 計算週區間

給定日期 D：
- 若 D 是**週一**：週區間 = (D − 7 天) 至 (D − 1 天)，即前一週的週一到週日
- 若 D **不是週一**：週區間 = D 所在週的週一 至 D 所在週的週日

範例：「上傳20260616週資料」→ 20260616 是週一 → 週區間 = 20260609～20260615

### 2. 讀取本機週索引檔

路徑：`C:\Users\Jeff Chen\iCloudDrive\Claude\my-agent\syntax-cards\week-YYYYMMDD-YYYYMMDD.md`

- 有檔案：讀取完整內容
- 無檔案：告知「該週無語法卡片紀錄」，停止流程

### 3. 確認後上傳

顯示確認訊息：
```
即將上傳 YYYYMMDD～YYYYMMDD 的語法卡片週索引：
共 N 筆卡片記錄
確認上傳嗎？（回覆「確認」即上傳）
```

使用者確認後，呼叫 `save_to_note_card`：
- **卡片標題**：`[YYYYMMDD-YYYYMMDD][語法卡片週索引]`
- **卡片內容**：週索引檔的完整內容

完成後告知：
```
✅ 語法卡片週索引已上傳！
卡片標題：[YYYYMMDD-YYYYMMDD][語法卡片週索引]
本週收錄：N 筆

⚠️ 提醒：請到 Heptabase 主空間，將此卡片手動移入對應白板。若已有舊版週索引卡，請手動刪除。
```
