# 語法卡片建立 SOP

## 分類系統

根據內容自動判斷，無需使用者選擇：

| 分類碼 | 適用內容 | 子分類選項 |
|--------|----------|-----------|
| `[AI]` | 給 AI 模型的提示詞語法 | 角色設定 / 輸出格式 / 思維框架 / 限制條件 / 情境注入 |
| `[IMG]` | 圖片生成提示詞 | 人像 / 場景 / 文字排版 / 圖表資訊圖 / 風格指定 |
| `[DB]` | AI 工具語法與指令 | Claude / Gemini / ChatGPT |
| `[LEARN]` | AI 學習筆記與創作方法 | 創作流程 / 工具技巧 / 提示詞策略 / 工作流整合 / 案例拆解（可複合）|

---

## 步驟一：自動產生標題並確認

收到語法內容後，根據內容：
1. 判斷分類碼（[AI] / [IMG] / [DB] / [LEARN]）
2. 判斷子分類（[LEARN] 可填複合型，例如：創作流程 + 工具技巧）
3. 產生簡潔的繁體中文標題

**標題格式**：`[P][分類碼][標題]`

**範例**：
- `[P][AI][鏈式思考提示框架]`
- `[P][IMG][夢幻向日葵田場景]`
- `[P][DB][Claude 系統提示角色設定語法]`
- `[P][LEARN][用 Midjourney 完成品牌視覺的完整流程]`

詢問使用者：
> 「建議標題：**[P][AI][XXXX]**，這個標題可以嗎？」

---

## 語言處理規則

存入前先判斷輸入語言：

| 輸入語言 | 處理方式 |
|----------|----------|
| **繁體中文** | 直接存入，不做轉換 |
| **簡體中文** | 無條件全文轉換為繁體中文後存入 |
| **英文** | 原文保留英文，額外新增【原文翻譯】欄位，填入繁體中文翻譯 |

---

## 步驟二：存入 Heptabase

標題確認後，直接呼叫 `save_to_note_card`，存入白板「學長AI系統」。

**卡片內容格式（繁體 / 簡轉繁）**：

```
【子分類】
（根據上方分類系統自動填入，例如：場景、角色設定）

【原始語法】
（完整保留原始內容；若為簡體則全文轉換為繁體中文）

【說明】
（一到兩句說明這個語法的作用與特點）

【使用情境】
（說明何時、為何使用這個語法）

【參考圖片】
（留空，使用者手動上傳）
```

**卡片內容格式（英文輸入）**：

```
【子分類】
（根據上方分類系統自動填入）

【原始語法】
（完整保留英文原文，一字不改）

【原文翻譯】
（將原始語法翻譯為繁體中文，完整對應）

【說明】
（一到兩句說明這個語法的作用與特點）

【使用情境】
（說明何時、為何使用這個語法）

【參考圖片】
（留空，使用者手動上傳）
```

存入後回覆：
> 「✅ 已存入 Heptabase 白板「學長AI系統」，卡片標題：**[P][分類碼][標題]**」

## [LEARN] 分類專屬流程

當判斷為 `[LEARN]` 分類時，標題確認後，**不直接存入**，改為先詢問三個欄位：

**詢問順序**（逐一詢問，等待回答）：

1. > 「你使用的 AI 工具是什麼？（【應用工具】欄位，可跳過）」
2. > 「有沒有你自己的心得或備註要加入？（【我的心得 / 備註】欄位，可跳過）」
3. > 「有參考來源要附上嗎？（【參考來源】欄位，例如文章連結、書名，可跳過）」

收集完畢後，存入以下格式的卡片：

```
【子分類】
（AI 自動判斷，複合型用「+」連接，例如：創作流程 + 工具技巧）

【核心概念】
（AI 根據輸入內容自動提煉 2-3 句核心觀念）

【應用工具】
（使用者提供；若跳過則填「未指定」）

【執行步驟 / 流程】
（AI 根據內容自動整理為可執行的步驟或流程）

【我的心得 / 備註】
（使用者提供；若跳過則留空）

【參考來源】
（使用者提供；若跳過則留空）

【參考圖片】
（留空，使用者手動上傳）
```
