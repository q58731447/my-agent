# 語法卡片建立 SOP

## 分類系統

根據內容自動判斷，無需使用者選擇：

| 分類碼 | 適用內容 | 子分類選項 |
|--------|----------|-----------|
| `[AI]` | 給 AI 模型的提示詞語法 | 角色設定 / 輸出格式 / 思維框架 / 限制條件 / 情境注入 |
| `[IMG]` | 圖片生成提示詞 | 人像 / 場景 / 文字排版 / 圖表資訊圖 / 風格指定 |
| `[DB]` | AI 工具語法與指令 | Claude / Gemini / ChatGPT |

---

## 步驟一：自動產生標題並確認

收到語法內容後，根據內容：
1. 判斷分類碼（[AI] / [IMG] / [DB]）
2. 判斷子分類
3. 產生簡潔的繁體中文標題

**標題格式**：`[P][分類碼][標題]`

**範例**：
- `[P][AI][鏈式思考提示框架]`
- `[P][IMG][夢幻向日葵田場景]`
- `[P][DB][Claude 系統提示角色設定語法]`

詢問使用者：
> 「建議標題：**[P][AI][XXXX]**，這個標題可以嗎？」

---

## 步驟二：存入 Heptabase

標題確認後，直接呼叫 `save_to_note_card`，存入白板「學長AI系統」。

**卡片內容格式**：

```
【子分類】
（根據上方分類系統自動填入，例如：場景、角色設定）

【原始語法】
（完整保留使用者貼上的原始內容，一字不改）

【說明】
（一到兩句說明這個語法的作用與特點）

【使用情境】
（說明何時、為何使用這個語法）

【參考圖片】
（留空，使用者手動上傳）
```

存入後回覆：
> 「✅ 已存入 Heptabase 白板「學長AI系統」，卡片標題：**[P][分類碼][標題]**」
